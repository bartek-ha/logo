# CorelDRAW Source Files

This directory contains the original CorelDRAW source files used in the development of the official logo of **Imkervereniging Delft e.o.**

---

## Document Structure

The main CorelDRAW file contains:

### Page 1
Final logo composition:
- circular seal design
- 100 mm diameter
- final typography
- finalized bee illustration
- official proportions and layout

### Page 2
Collection of individual graphical elements used in the logo construction, including:
- head with antennae
- thorax with legs
- abdomen
- front and rear wings
- text
- hexagon

---

## Purpose
The second page is intended for:
- future modifications
- scaling adjustments
- export preparation
- reconstruction of elements
- archival purposes

---

## Recommended Export Formats
The final logo should preferably be exported as:
- SVG
- PDF
- PNG (transparent background)

---

## Notes
The CorelDRAW source files are considered the master design files of the project.

Please preserve:
- object structure
- layer organization
- original curves and proportions
- typography alignment
- color definitions

Unauthorized modification or redistribution is not permitted without permission from **Imkervereniging Delft e.o.**
